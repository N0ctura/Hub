Wolvesville Studio

Catalogo completo degli oggetti e creatore di skin, con il motore grafico ufficiale del gioco.

API key non configurata

Il sito usa la Wolvesville Public API con la chiave del proprietario, iniettata automaticamente alla build dai GitHub Secrets.

  1. 1. Apri il repository GitHub → Settings
  2. 2. Secrets and variables → Actions → New repository secret
  3. 3. Nome: WOLVESVILLE_API_KEY, valore: la tua API key
  4. 4. Fai ripartire il deploy (push o re-run dell'action)

Per provare in locale: crea un file .env.local con NEXT_PUBLIC_WOV_API_KEY=la-tua-chiave e rifai la build.
